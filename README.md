# 📊 Sales Forecasting Dashboard

An AI-powered **Sales Forecasting Dashboard** built using **Python, Flask, Pandas, Plotly, and Prophet**. This project helps analyze historical sales data, generate future sales forecasts, and provide interactive business insights through a modern web dashboard.

---

# 🚀 Overview

The Sales Forecasting Dashboard enables businesses to monitor sales performance, analyze trends, identify top-performing products and regions, and forecast future sales using machine learning. It combines interactive visualizations with AI-generated business recommendations to support data-driven decision-making.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/anishsahu01/sales-forecasting-dashboard.git
```

Navigate to the project folder

```bash
cd sales-forecasting-dashboard
```

Install the required packages

```bash
pip install -r requirements.txt
```

Run the Flask application

```bash
python app.py
```

Open your browser and visit

```
http://127.0.0.1:5000
```
